# Project implementation rules

- `spec.md` is the product source of truth.
- Keep Gemini credentials on the server. Never return private solution fields before a saved accusation.
- Keep route handlers thin; validate requests at boundaries and place domain behavior in services.
- All generated stories and evidence are fictional. Label image placeholders and CCTV transcripts accurately.
- Keep `.env`, generated user cases, and secrets out of version control.
- Document any unimplemented acceptance criteria accurately; do not describe unverified behavior as tested.
